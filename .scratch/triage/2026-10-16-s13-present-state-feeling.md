系列：R3 补轮 [S13]——感受的当下性缺失（state 通道）

## 现象（语义取证）

「当下的感受」标题指此刻，内容全部来自过去：mood=近 20 条 L1 经历的半衰期聚合（trait 式基线），价值锚清单=历史挖掘的恒定集合。当前任务是什么、用户刚说了什么、这一轮发生了什么——对感受层贡献为零。

## 第一性原理分析

心理学 trait/state 区分：mood 聚合是 trait（稳定倾向），而感受必须含 state（此刻状态）。最小自我（Gallagher）=此时此地的体验主体。TDB 的感受层是一个「没有现在的现在时」：

1. 模型读到「近期基调：偏积极」但完全不知道「这个任务让我处于什么状态」——情境评价（appraisal）缺位；
2. 任务语境变化时感受不变（排查任务 vs 写文档任务应产生不同紧张度），感受层对行为校准零贡献；
3. 与 #28（trait 精度升级）正交：#28 把基线做细，本票补 state 通道，二者并存（基线 + 情境修正）。

## 方案（方向）

- state 通道：每轮从当前任务/最近轮次计算情境评价（任务类型、用户消息语气、上轮结果成败），叠加在 trait 基线上。
- 产生机制 config-first：规则版先行（任务类型映射表），LLM 评估版后置；无信号=省略（宁缺毋滥，禁伪造）。
- #25 命名联动：state 落地后「当下的感受」可能名实相符，命名拍板推迟到本票定案后。

## 验收标准（拍板后细化）

- 同一历史基线下，不同任务语境产生不同 state 输出（区分度断言）。
- 无情境信号时 state 段省略；R-A 红线不破；确定性（同输入同输出）。
