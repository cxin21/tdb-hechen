## 第一性原理分析

叙事同一性的最小要求是**跨时间持存**（SEP Personal Identity：persistence through time）——不落历史的状态无法支撑「演化」叙事（[S6] 反思回路也需要历史窗口做原料）。

Graphiti 的 bi-temporal（valid_at/记录时双时间线、失效不删除）与 TDB 红线「禁删记忆」哲学同构：状态被替换时旧值标 invalid 而非删除。

工程事实：#6（M4）正在补 L1 记忆图边的失效 API 与区间过滤——机制同族，soul 状态历史化可直接复用其表结构与 API 形态，避免第二套 bi-temporal 实现。
