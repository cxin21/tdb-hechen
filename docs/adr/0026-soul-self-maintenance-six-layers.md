# ADR-0026 自维护人格灵魂：六层 + 确定性判据 + 账本可回滚（0 人工采纳）

- 状态：已实施（2026-11-05）
- 决策者：何晨（拍板「全部 LLM 自动维护，全生命周期 0 人工参与，要降级/停用/更新/合并」）
- 相关：ADR-0019（人格注入预算）、ADR-0024（选线标准档）、`docs/soul-self-maintenance.md`（运行手册）、`MemoryCore/src/core/soul/`

## 背景：三个结构性错位

1. **存输出不存函数**：`core_memory.self_identity` 用 8 行滚动窗（`identity-discovery.ts:682/740`）保存「我做过什么」，第 9 条静默挤掉最旧一条，无历史无标记 —— 于是生产里「我是谁」20 天整块变 11 次。
2. **三层压一层**：特质层（我是谁）、特征性适应（我怎么做）、叙事层（我的来路）共用一槽；关系层缺失（`identity` 槽装的是「我心中的他」= 用户画像），方法论与事件报告被当作身份渲染进提示词。
3. **改动不可逆所以必须有人**：面板采纳先翻 `adopted` 再写槽，写失败不回滚（`v2-router.ts:2764` vs 原子版 `auto-adopt`）；而人审在 2026-10-25 后停摆（405 rejected / 36 pending 积压），生产线继续产提案 —— 人在环不是安全，是断点。

## 决策

### 1. 人格 = 可判定的取舍函数，不是经历摘抄

判据只有一条：**两件事打架时我站哪边**（values），以及 **即使有用也不做**（boundary）。因此：
- 方法论（怎么做）永远不进人格层，进 `method` 审计池（可查、不注入）。
- 事件句、阶段词、项目专名、任务锚（commit/issue/路径/工具名/比例/枚举）一律不进人格层。
- 长句（identity >90 字、values/relationship >110 字、boundary >120 字）视为「在讲一段经历」而非「一条取舍」。

### 2. 分成六层，各自有时间尺度与写入频率

| 层 | 内容 | 变化节奏 | 预算（字） |
|---|---|---|---|
| voice | 说话方式/语气 | 季度 | 600 |
| identity | 我是谁（换项目仍成立） | 月 | 400 |
| values | 冲突时站哪边（两难句） | 月或事件 | 320 |
| boundary | 我不做的事（禁令+场景） | 只增不减，只 retire | 2600（免裁剪） |
| relationship | 我和他的关系（须原话/记录证实） | 周 | 900 |
| narrative | 我的来路（只引 episode） | 季度 | 300 |
| method | 方法论审计池 | 不限 | 0（不注入） |

### 3. 0 人工成立的前提：改动能回滚

人审之所以必要，只因改动不可逆。于是把「不可逆」从系统里删掉：
- `soul_persona`：条目状态机 `active/degraded/frozen/merged`，删除=转 `frozen`（保留可复活），合并不销毁（被并者 `mergedInto` + host.aliases 可拆回）。
- `soul_ledger`：append-only 账本，每条准入/拒绝/更新/合并/降级/停用/复活/漂移/预算省略都记 `before_hash/after_hash/gates/reason/evidence`，`entryId` 幂等。
- 一件写入 + 账本 + 状态在同一事务（`commitSoulPersona`），失败整批回滚。

### 4. 四机制用确定性判据，不靠 LLM 自我评价

- **更新**：`alpha=0.15` —— 单次整块改写 diff 超 15% 直接拒（不许「人格翻修」）；7 天内同层整块改写 ≥1 次即 churn 拒。
- **合并**：同层相似度 ≥0.85 → 并成一条，保留 weight 高者，另一条转 aliases（可拆回）；已 `merged` 的条目不再当候选（否则每轮重新合并一次、账本无界增长）。
- **口径重算**：层归属是 `f(文本, 来源槽)` 纯函数，分类规则升级时就地换层（`reclassify`），不靠「同文再收一条」纠正——那会在两层各留一份。
- **降级**：30 天无新证据、或矛盾计 1 次 → `degraded`，weight ×0.7，仍注入但靠后（`degraded_tail`）。
- **停用**：矛盾 ≥2 次、90 天无证据、或漂移 <0.6 → `frozen` 退出注入（数据保留可复活）。
- **漂移**：与近期语料/锚比 cosine；连续 3 次 <0.75 降级、<0.6 停用。voice 轨允许自我复位，判断轨（values/boundary/narrative）**永不自我复位**（`canSelfReset`）。

### 5. 情绪与心境分离（必须有对象）

- 情绪 = 有对象、半衰期 3h 的评估产物（OCC 十四模板：振奋/踏实/笃定/悬着/恼火/失望/不安/愧疚/害羞/委屈/开心/安心/意外/平静），由 `appraisal` 五维（目标相关/预期违背/可控性/规范相容/归因）确定性映射，不调 LLM。拟人化四类由评价维度路由（公开＋自己过失→害羞；私下＋自己过失→愧疚；对方造成→委屈；公开肯定→开心；自己收口→安心），2026-11-06 增补，仍是不调 LLM 的纯函数。
- 情绪对象史优先于心境数值：同一对象出现过几次、修没修好，是事实，不随半衰期消失；注入侧据此给判断（「同类再出现先挡一下」「先核对修复是否还在」）。原因行不等强度回到阈值——3h 半衰期下必然衰减到零，等强度等于永久缺席（2026-11-06 改）。
- 心境 = 无对象、48h 半衰期的积分状态，注入只写「比基线偏积极/偏沉」的**相对**偏移，不写绝对档位 —— 绝对档位是伪精度。
- 两者都落 `soul_state`（valence/arousal + baseline + sampleCount），与召回侧 `moodSign`（排序信号）解耦：情绪不再被当作排序参数误用。

### 6. 存量槽的接管语义

开启后首轮 `worker` 把 `core_memory` 的 `self_identity/identity/strict_rule` 逐行导入人格层（`legacy=true`：用户原话豁免形态门，但事件句仍拦）。人格层 `identity/boundary` 一旦有 active 条目，注入侧即停止重复渲染旧两槽与旧红线段 —— **同一约束不再两处承载**。若人格层为空（worker 从未跑过），接管门不开，逐位保持现状（开门不清空身份）。

## 后果

- `soulMaintenance.enabled` 缺省 false：老部署逐位不变。
- 生产校准：582 条历史提案回放，catchRate **97.0%**（645→见运行手册），残余 12 条误收逐条列出、可解释（多为「原则+举例」的短红线）。
- 生成侧（`identity-discovery` / `reflection`）保留但视为**候选来源**，不再直写身份槽；提案门退化为「上游建议」，最终准入由本层判据决定。
- **红线层免裁剪**：`boundary` 跳过渲染字预算（`BUDGET_EXEMPT_LAYERS`），上限由 `maxItems=40` 兜；理由是不变量集少一条就多一次越界机会（生产实测 29 条 / 2372 字，原 900 字预算会在导入期判死 18 条）。预算只治理渲染，绝不治理准入——这一条是 2026-11-05 生产预览暴露后回改的。
- **存量导入不丢行**：29 条红线全量进 `boundary`，方法论与事件进 `method`（不注入），用户事实进 `relationship`。`rejected=0` 是设计：导入不是二次审判，裁决在渲染与四机制侧。
- **更新是真机制，不是摆设**：改写候选先按同层相似度 ≥0.55 判「这是同一个条目的新表述」→ 走 α 有界改写（原地改 itemId，不新增并存旧说法）+ 变更率窗口（7 天 1 次）+ 单轮上界 3。2026-11-05 之前这里是死代码（`planUpdate`/`diffRatio` 声明后零调用，改写文本被直接丢弃），补齐时发现 α 必须用编辑距离而不是 bigram 相似度，否则短句改 1 字就超 α，更新永远跑不动。
- 节流真接线：`updateIntervalHours` 曾是无引用的死配置；现在靠 `soul_ledger` 的 `cadence` 条目做锚点（不改 `soul_state` 结构），到期待整合、未到期如实跳过。
- 接管门覆盖叙事段：人格层 `identity` 有内容后，旧槽的「我是谁」叙事段（`identityNarrative`）也停止渲染——否则同一身份在提示词里出现两遍，一份来自 8 行滚动窗、一份来自人格层。人格层为空时叙事段照旧，开门不清空身份。
- 心境是增量积分：只吸收 `soul_state.updatedAt` 之后的信号（5 分钟重叠）。此前每 tick 把 4 天窗口重新加权一遍，`sampleCount` 会无限膨胀、旧事件被反复记功。
- 未采集：真实部署下的漂移分数分布、LLM 改写器在长语料上的产出率、跨月 churn 实测、更新链在生产语料上的实际改写量。
