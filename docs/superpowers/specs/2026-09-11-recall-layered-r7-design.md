## 0. 设计读

> 一句话：召回从"一层平铺的经验"升级为"**两层渐进披露**"——L2 持续态结论（浓缩稳定、cache 友好）常驻注入，L1 经验明细按预算折叠在后（scene_name 反查 + coreRef 辅助）；九通道保留在 L1 层，宁缺毋滥不变。

## 1. 两层模型

```
注入块
├─ 第一层 · L2 结论（常驻，稳定，cache 友好）
│   场景持续态结论（durative work_fact / scene blocks）
│   按 query→scene 命中选择；无命中则本层空
├─ 第二层 · L1 经验（按预算折叠，九通道照常）
│   scene_name 反查（part_of 证据链优先 + 同 scene 过滤）
│   + coreRef 辅助（同价值经验）
│   + 既有九通道候选（R1-R6/R8/R9 排序不变）
└─ 预算：结论层 50% / 经验层 50%（注入 limit 对半；结论不足时余额给经验）
```

## 2. 机制规格

### R7-1 · L2 结论层选择
- 数据源：既有 L2 通道（场景持续态——consolidation 产物 durative work_fact + scene blocks title+snippet 通道，历史已存在）
- 命中：query 与场景结论的匹配（文本命中 + scene_name 命中，沿既有 L2 注入的匹配逻辑）
- **幂等/防重**（借团队 幂等与防重 机制的精神）：结论未变化的场景不重组注入（E3 会话复用同款原则——结论层稳定=cache 友好）

### R7-2 · L1 经验层（scene 反查 + coreRef 辅助 + 九通道）
- scene_name 反查：part_of 证据链（consolidation 建的证据边，现成数据）+ 同 scene 过滤
- coreRef 辅助：同价值经验（R5 反查通道的 L1 层已有——复用）
- 九通道排序不变（R1-R6/R8/R9）
- 预算：limit 对半切（结论层用剩的给经验层）

### R7-3 · 注入形态
- 结论块在前（带 `[结论]` 标注）+ 经验折叠在后（现状标注体系保留）
- 无 L2 命中 → 纯经验块（现状退化，零行为差异）

## 3. 不变式
- 九通道/绝对门槛/租户隔离/降级标注零变化
- 无 L2 命中 → 与现状逐位一致（退化安全）
- golden 锚点：R7 实施前后各一锚（分层是注入形态变更，锚点分化记录）

## 4. 验收
- golden 双锚（前/后）+ 分层断言（结论层在场/经验折叠/预算切分/无 L2 退化）
- 人工验收：注入块形态目检
