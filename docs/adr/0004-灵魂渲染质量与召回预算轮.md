# ADR-0004：灵魂渲染质量与召回预算轮（2026-10-19）

状态：已采纳（本轮质量轮批次落地并经真实数据 E2E 验证）。上级：ADR0003 灵魂规约。关联：docs/research/2026-10-19-soul-rendering-survey-2025-2026.md、docs/research/2026-10-19-soul-first-principles-gap-analysis.md、docs/audit/2026-10-19-core-values-redundancy-audit.md。

## 背景

生产实拍（真实 tenant /v3/recall）注入块呈「半成品」形态：价值锚同质扎堆（6/10 同族）、红线墙占块 60%、感受段泄露实现细节、承诺行话直出、且冷进程召回链 5-20s 触发 504——灵魂经常根本到不了 prompt。调研（FormatSpread/ID-RAG/MMR/2604.02236）确认：格式是行为变量；多样性是检索侧标配；绝对相似阈值在跨模型语义空间无分离度。

## 决策

1. **MMR 多样性替代绝对阈值去重**：情境锚选择（rows>maxRows 裁剪发生时）以 λ=0.7 贪心 MMR（val=λ·rel−(1−λ)·maxSim）替代纯 top-K；未裁剪=声明序原样（D3 选项C 门）。理由：20 锚实测 cosine 无分离阈值（重复对 0.669 vs 非重复对 0.653），embedding 去重通道保留为诚实 no-op（阈值 0.85 保留 config-first）。
2. **锚预嵌软预算 1200ms + 降级不缓存**：scoreAnchorRows 并行预嵌（unique desc 去重后 Promise.all），超预算抛错回退声明序；降级渲染跳过 soulPrefixCache 与 soul 快照落账（缓存污染/假阳性格局行防扩散）；in-flight embed 后台落缓存。函数级缺省 0（单测零行为变化），生产 config 注入。
3. **embedAnchorCached 共享缓存**：锚向量缓存+in-flight 并发合并（FIFO 100），scoreAnchorRows/dedupeAnchorPairsEmbedding/suppressAnchorOverlapRows 三通道共用——同 desc 全链零重复付费。失败不缓存（下次重试）。
4. **query-expand 黑洞治理**：hybrid-fallback 路扩展词 race 热路帽 hotPathTimeoutMs=1500（0=旧行为）；失败负缓存 negativeTtlMs=30000；空结果按正 TTL 缓存（LLM 确定答「无扩展」≠失败）。expandMs 语义=热路实际等待快照。
5. **rerank 常驻 + 启动预热**：local rerank idleUnloadMs=0（config-override 已固化）；server start() 进程级 fire-and-forget 预热（getSharedLocalReranker 同池）——#64 脚本式预热救不了新进程首召回。
6. **红线治理**：去重单一源不变（soul-redline-render.ts）；strictRuleDedup.maxLines=8 截断（保前 N）；suppressAnchorOverlap=true 锚行 desc 与红线行近重复（jaccard+可选 cosine）时锚行让位——软硬同文只留红线面。
7. **感受段去泄露**：moodTier 行固定文案去实现细节括号（「近期基调：偏积极。」）；聚合口径移观测侧（soul-state 聚合/日志），不进 prompt。
8. **承诺工件治理**：E2E 工件按数据修复清理（soul_promises/soul_promise_events/core_pending 三表）；不新建代码门（v2-router promise_create 预检已在）。
9. **入库端语义查重=提案制，不自动合并**：发现端只读（K1 合同）维持；discover 通道 containmentGate opt-in 开启（G-SIMMERGE 增长路不开，兼容其合同）；存量冗余按审计报告人工裁决（retireValue 已有）。

## 后果

- 注入面：锚序从「value_id 稳定序+同质扎堆」变为「MMR 多样代表」；红线 10→8 且去同文；感受段无括号。soulVersion/cacheKey 指纹相应扩展（mmr/eb/max/sup 段）——升级后首个请求为缓存冷启动，属预期。
- 性能：冷进程首召回 5120ms(504)→3849ms(200)；warm 13ms；soul 段 12s→20ms；expand 不再阻塞主路（帽内 race，后台落缓存）。
- 兼容：全部 config-first，缺省安全（函数级缺省 0/关，生产 yaml 显式开）；G-SIMMERGE/anchor-growth 增长路行为逐位不变（containmentGate opt-in 锁定）。
- 真实性边界（ADR0003 §真实性）不变：只做整行/整锚选择（drop），kept 逐字保留；确定性零随机零时钟零 LLM（D9）。
