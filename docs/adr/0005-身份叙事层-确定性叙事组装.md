# ADR-0005 身份叙事层：确定性叙事组装（#67，R3）

日期：2026-10-19　状态：已采纳　派生：issue #67（设计文档 `docs/research/2026-10-19-r3-identity-narrative-layer-design.md` §4 即票面）

## 背景与定位

Park et al. 2411.10109 的记忆系统以**叙事文本**承载用户画像，而本仓库以**结构化条目槽**（identity / self_identity，单槽合并演化 version++）承载同一信息。二者不是替代关系：**条目存储 + 叙事渲染并存**——存储合同（identity-discovery 提案门、version++、perTurnSlots 布局门）一律维持现状，叙事只在渲染侧派生。要解决的问题是：条目行（`- [self_identity] 我是测试者。`）是给记忆系统看的形态，注入给模型的身份上下文缺一段可读的第一/第二人称叙事。

## 决策

1. **A 案：确定性叙事组装器**（不做 LLM 改写、不做检索式摘要）。单一源 `MemoryCore/src/core/hooks/identity-narrative.ts`：`renderIdentityNarrative(slots, opts?) → string | null` 纯函数——模板常量 + 事实句逐字保留，无 LLM / 无随机 / 无时钟；同输入 ⇒ 同字节。仅 identity / self_identity 两槽叙事化；strict_rule（红线）与价值锚不在其列。
2. **双路同源**：soul 块会话头（MemoryCore `soul-assembler.ts`，identityNarrative 选项开启时以叙事段替代身份条目行）与 system 侧 core_memory（`v2-router.ts` `handleCoreMemoryRead` format=narrative，返回合成槽 `identity_narrative`）两路都调同一 `renderIdentityNarrative`，禁双份实现。MemoryProxy 经 `/v3/core-memory/read` API 透传消费（`listCoreMemories(identity, { format: "narrative" })`），proxy 侧零组装逻辑（soul-dedupe / redline-render 的镜像 parity 合同不新增文件）。
3. **真实性守门三闸**（全部可测试）：
   - **生成闸（溯源断言）**：`verifyNarrativeProvenance`——叙事输出 ⊆ 模板常量 ∪ slots 原文子串；违例整段丢弃退回条目渲染（宁缺毋滥，同 ADR-0003 §4）。
   - **写入闸**：叙事单向 slots→渲染，永不回写存储；实现上纯函数无副作用即可（合成槽 `source: "narrative"` 仅存在于 API 响应，不入库）。
   - **预算闸**：超预算整句丢弃（truncateByLines / applyAnchorBudget 同哲学——首句超限即尾丢，不截半句），保留句逐字。
   - 安全：写路径已有单点转义（v2-router `handleCoreMemoryWrite` escapeXmlTags，P2-T11 咽喉位），读端逐字直出即满足溯源子串性，不做二次转义（会破坏「原文子串」断言）。
4. **模板指纹（ADR-0003 §5 批次纪律）**：`NARRATIVE_TEMPLATE_VERSION = "nv-2026-10-19-1"` 首批声明；nv 段参与 soulPrefixCache cacheKey（仅 identityNarrative 开启时出现，缺省 cacheKey 逐字节不变）；同 sv + 同 nv ⇒ 同叙事字节；模板文案变更换新 nv 值一次性声明，soulVersion(sv) 不翻（数据驱动）。
5. **配置**：`coreMemory.soulRender.identityNarrative.enabled`（缺省 **false**，关=逐位现状）；本地 `MemoryCore/tdai-gateway.yaml` 与云端 `deploy/tencent-cloud/config/core/tdai-gateway.cloud.yaml` 声明 enabled: true。
6. **perTurnSlots=false 不推翻**：它是双注入去重布局门，非「身份不注入」；identityNarrative 与之正交（idNarrSkip 时身份条目行让位叙事段，dedup 语义不变）。

## 后果

- 身份叙事可读化且零幻觉面：叙事内容完全可溯源到条目原文，LLM 无从注入。
- 存储合同零改动：identity slots 的提案门 / version++ / 条目渲染路径全部保持现状；Park 口径（条目存储+叙事渲染并存）以注释形式钉在 `identity-narrative.ts`、`soul-assembler.ts`、client/injector。
- proxy 无第二实现：升级模板只改 MemoryCore 一处 + nv 值；镜像 parity 文件集不变。
- 测试：`MemoryCore/src/core/hooks/__tests__/identity-narrative.test.ts`（溯源/预算/确定性/集成/cacheKey nv 隔离/sv 不变）+ `MemoryProxy/src/injection/injectors/__tests__/identity-narrative-injector.test.ts`（请求契约/透传/门关兼容/旧契约逐字节）；既有 `soul-assembler-per-turn-slots.test.ts` 不改一字。
