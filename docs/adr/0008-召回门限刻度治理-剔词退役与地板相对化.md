# ADR-0008 召回门限刻度治理：候选集占比剔词退役与 BM25/Rerank 刻度相对化

- 状态：已接受（2026-10-25，#99 拍板「F1-A 最小改动 + legacy 双轨兜底」；实施 commit d45b854，用户授权）
- 关联：#99（实施票，已关）、#96（密闭评测基线，已关）、#53（idfWeighted 排序消歧）、R71-A1/A2（bm25 地板 / 结论 rerank 门）、issue #2（P1 万词面剔除门，被本决定退役）

## 背景

#96 密闭口径取证的 P3 真分歧（golden「给我一个可复制的提示词，不要文档」零召回、锚在库）揭示门限体系三个刻度缺陷：

1. **候选集占比自指**：textHitMaxTokenRatio 用「token 命中候选占比」判万词面，而候选集经 buildFtsQuery FTS 预筛天然含查询 token——占比恒≈1，最贴题 token 反被剔（「提示」2/2=100%>0.5 → 结论层 0 行；旧兜底只救「全部被剔」）。
2. **BM25 绝对地板漂移**：minBm25Rel=6.5 是 2026-10-19 语料定标，BM25 分为语料相对值（非可比绝对值，search-at-depth ch3-s2），库增长（l1_archive 已 6444 行）使其语义持续漂移。
3. **未校准分数对拍门槛**：local reranker 输出原始 logit（rank-correct 非校准，ZeroEntropy score-calibration 口径），对拍固定门槛致经验层全杀（P3：topScore −2.82 < −1.0 全杀 12 条 → 0 行）。

业界口径：ES 7.3 弃用 common-terms 查询、让 BM25 IDF 自行降权；min_score 应在归一刻度上设定；reranker 多数仅 rank-correct，需校准后才可阈值化。

## 决定

1. **F1 · 候选集占比剔词整体退役**（对齐 ES 7.3 弃用 common-terms 方向）：textHitMaxTokenRatio 键三面退役（L2MatchInputs / config 解析 / yaml）；textHit 基线 = 全 token OR（最松层），万词面降权唯一机制 = #53 idfWeighted 排序消歧（排序而非裁剪）。票面「递进放松阶梯（AND→top-2→OR→纯向量）」不实现：A 案下基线即最松层，「层空下降一层」由结论层空 → 预算全额让渡经验层（splitBudget 既有行为）结构化承载，收紧档反而动其余探针基线。
2. **F2 · bm25 预地板刻度无关化**：门槛 = α×topRel（conclusionLayer.minBm25RelRatio，clamp [0,1]，起步 0.4；topRel=本候选池最大 raw rel）；legacy minBm25Rel 绝对分保留为未迁移部署兜底（行为逐位不变），并存时相对门优先；kept-count 上限逻辑不动；bm25Rel 缺席候选豁免不变（宁缺毋滥）。
3. **F3 · rerank 刻度校准化 + 优雅降级**：local logit 先 sigmoid 归一 0..1，门槛同变换 sigmoid(minScore)（单调等价，接受/拒绝边界与 raw 逐位一致）；**全员低于阈值不清零**——回退未重排顺序（与 null/throw/熔断同族原序语义），journal `degraded:"all-below-minScore"` 归因 + scoreScale/top01/threshold01 观测；结论层 rerankGate 同款降级+归一化（生产维持 shadow-first，切 enforce 已预置）。阈值标注对校准（票面可选支）暂缓：golden 仅 9 探针不足「几十对」。
4. **兼容承诺**：未迁移 yaml 行为逐位不变（legacy 键照常解析，相对门仅显式配置才启用）；九通道/RRF/字典序等检索排序语义零变化。

## 理由

- **自指统计必错**：预筛候选集上的「常见」≈「贴题」，占比剔除把召回信号当噪声——这是结构缺陷而非参数问题，调参不可救。
- **刻度无关优先**：库是活的；绝对门每次库变都要人工重定标（必然被遗忘），相对门把定标从「绝对数字」变成「分布位置」。
- **降级优于清零**：门的全杀路径把「分数不可信」放大成「召回为零」；回退到已知良好的未重排序 + journal 归因，把不确定性留在观测层而非输出层。
- **双轨而非替换**：生产 yaml（gitignore 本地配置）与 cloud 部署的迁移节奏不同步，legacy 兜底消除「未迁移即静默失去地板」的部署风险。

## 后果

- 生产生效需网关重启（tdai-gateway.yaml 已迁移：textHitMaxTokenRatio 退役墓碑注释 + minBm25RelRatio: 0.4）。
- precision proxy 0.304→0.25（被救回行稀释每行口径；高价值命中 7→8，总行 23→32）——接受；机理与对抗探针归因见 docs/research/2026-10-25-99-heldout-probe-evidence.md。
- 遗留：阈值标注对系统校准（待数据）；cloud yaml 迁移随部署协调；结论门 enforce 待 shadow 观测期数据拍板。
