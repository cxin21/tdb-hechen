# 星图 UI 验收用例（人类用户视角）

更新时间：2026-11-11
被测对象：MemoryPanel 五体星图（/）与其四个子页面（/memory、/wiki、/code、/skills、人格页）
测试手段：headless Chrome + CDP，脚本 \`.scratch/ui-harness.mjs\`，用例步骤 \`.scratch/steps-*.json\`
前置：面板 8123 在跑；localStorage 注入 session + tdai-memory.activeTeam.v1=team-2k12lgb650 + tdai-memory.starmap.agent
判定：任何一条失败都要给出截图、DOM 断言值与期望值；修完重跑同一条。

## M1 全景与布局
- T1.1 首屏 15 秒内出现 \`.fb-canvas\`，\`[data-testid=five-bodies]\` 的 data-counts 非空。
- T1.2 四团云在画布内全部可见（云心 ± 半径不出画布），任意两团云的椭圆不相交。
- T1.3 每团云的标签胶囊含「名称 + 计数」；总数为 0 的云显示「暂无」，不显示裸 0。
- T1.4 中心「人格恒星」标签与副行（字数/版本/块数）清晰，不被任何云或光点压住。
- T1.5 忆云四条环线与 L3/L2/L1/L0 角标可见，角标不叠在标签胶囊上。
- T1.6 窗口 1280x720 与 1920x1080 各截一张，布局不重叠、不溢出。

## M2 交互
- T2.1 拖拽 200px 后画面角度改变（截图字节差 + 云心位置变化），松手不误触发跳转。
- T2.2 滚轮向上以指针为锚放大，指针下的星点位移前后一致（±8px）。
- T2.3 滚轮缩放范围夹在 0.55–6 倍，超限后继续滚动无变化。
- T2.4 空格暂停：底部提示变「已暂停 · 空格继续」，再按恢复。
- T2.5 输入框聚焦时空格不触发暂停（焦点不在 body 时）。
- T2.6 R 键归位：视角与聚焦态同时复位。
- T2.7 Esc 归位。
- T2.8 单击云进入聚焦：胶囊出现「云名 / 进入 / 返回全景」，云心落在画布中心 ±24px。
- T2.9 聚焦态点空白处退出聚焦。
- T2.10 双击云直接进入对应子页面，路由与云一致。
- T2.11 单击中心人格恒星进入人格页。
- T2.12 刷新按钮重新取数且不重置当前视角以外的页面滚动。

## M3 忆云（L3/L2/L1/L0）
- T3.1 四层 total 与 BFF \`/chat-memory/layer\` 返回一致（当前基线 L3=1、L2≈17、L1≈11497、L0≈14790，允许新写入增加）。
- T3.2 四层计数单调：L0 ≥ L1 ≥ L2 ≥ L3；不一致时星图要在 errors 里报。
- T3.3 忆云星点按层着色（L3 青、L2 橙、L1 蓝、L0 灰蓝）。
- T3.4 进入 /memory 后列表首屏条数与星图 L0 计数同一数据源。
- T3.5 1.4 万点场景下拖拽/缩放无掉帧超过 200ms（用 requestAnimationFrame 采样）。

## M4 典籍云（wiki）
- T4.1 挂到当前 agent 的 wiki 亮、未挂载暗；暗星仍可见不是消失。
- T4.2 wiki 数 3 个（wiki-m6c41uvc、wiki-s5obgst6 就绪；wiki-sm8cdo1j failed）时，失败态不画成正常亮星。
- T4.3 云标签显示「总数 · 挂载数」，与 \`knowledge/wiki/list\` + agentFixed 一致。
- T4.4 进入 /wiki，列表条数与云计数一致。

## M5 构筑云（code-graph）
- T5.1 code-graph 总数为 0 时显示「暂无」并画虚线轮廓，不呈现成一团黑。
- T5.2 有数据时最小星点为具体块（仓库/文件），点进入 /code 列表一致。
- T5.3 code-graph 接口 501/404 时星图 errors 报「code」而不是整体白屏。

## M6 技艺云（skills）
- T6.1 总数与 \`skill/list\`（无 agent 过滤）一致，挂载数与带 agent_id 的结果一致。
- T6.2 挂载亮、未挂载暗，暗星仍可点（进 skills 页应能看全量）。
- T6.3 当前基线 340 总数 / 51 挂载；若界面显示 340/340 视为失败。
- T6.4 团队可见资产为 0 时显示降级提示，而不是只画亮星。

## M7 数据与容错
- T7.1 任一接口 500/超时，页面出现「部分未采集：xxx」，其余云照常渲染。
- T7.2 首屏请求数 ≤ 6（当前 9，聚合接口缺位）。
- T7.3 未选团队/智能体时显示「先选团队与智能体」，不空白。
- T7.4 越权 agent 的资产不出现在星图上（权限边界）。

## M8 可达性
- T8.1 Tab 依次可达「刷新」「进入」「返回全景」。
- T8.2 画布有 aria-label 描述可交互动作。
- T8.3 对比度：标签正文与底板对比 ≥ 4.5:1。

## 已发现的疑似缺陷（待验证）
- D1 技艺云 mounted 显示 340/340，而按 agent 过滤只有 51 → overview mounted 口径疑错。
- D2 首屏请求 9 次（9 个串行请求），超过目标 6。
- D3 构筑云 total 0 但云体仍存在焦点热区，点进去是空页（需空态）。
