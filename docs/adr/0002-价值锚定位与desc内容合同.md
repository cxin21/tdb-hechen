# ADR-0002 价值锚定位（软取向轴，非规则）与 desc 内容合同 v2

- 状态：accepted（2026-10-14，维护者授权定案，issue #20 cxin21/tdb-hechen）
- 关联：ADR-0001（值信号租户口径与维持现状裁决）；issue #20 / #7 / #11

## 决策

1. **价值锚（core_values）定位 = 软取向轴，不是规则。** 三层分工：

| 层 | 载体 | 生效方式 | 写入门 |
|---|---|---|---|
| 叙事层 | identity / self_identity 槽 | 注入正文直接陈述"我是谁/我心中的他" | 采纳门（证据）+ imposition 门 |
| **取向层** | **core_values 锚（theme/person/character）** | **带权重与方向的偏好轴，经四消费点间接生效（见下）** | **证据门 + 人工/自动采纳护栏** |
| 规则层 | strict_rule 槽 | 硬约束，全有或全无（人工裁决，V12-ADJ 合并保留既有行） | 仅 pending 人工采纳，永不自动写入 |

2. **desc 内容合同 v2（单一源 `MemoryCore/src/core/hooks/anchor-desc.ts` 的 `DESC_CONTRACT_V2` / `descContractPromptLine` / `passesDescContractV2`）**：锚描述一句话（≤60 字）=「情境短语 + 行为取向」——写清*在什么情境下倾向于怎么做*（宁可…不…／遇…先…／…时优先…／…而非…）；禁纯定义句（"X 很重要"）与事件叙述（episode 门同源）。好例：「涉及不可再生数据时，宁可慢一步验证，不做不可逆操作。」三处 prompt（theme DISCOVER / PERSON 4b / CHARACTER）与存量审计脚本共同引用该单一源，重复定义=0。

## 论证

- **锚 ≠ 规则**：锚的采纳走证据门（minEvidence、语料逐字/滑窗命中），证据是概率性的——若把锚当规则，等于给硬约束引入概率性存在（证据 4/5 时规则"半生效"是不可接受的语义）。规则的生命周期是人工全量裁决（adopt/reject），锚的生命周期是证据升降（retire/reweight）——两者生命周期互斥，不可混载。规则请写 strict_rule 槽提案。
- **为什么合同 v2 强调"取向"而非"定义"**：锚经消费点间接生效，消费点需要的是*行为倾向*信号（fired 加成方向、生成端软引导），"X 很重要"不携带可执行取向；且定义句与 label 重复（label 已经是名字）。
- **确定性预筛而非 LLM 裁决**：`passesDescContractV2` 只做取向特征 + 非定义句启发预筛（宁缺毋滥口径），预筛失败仅提示、不阻塞人工输入；LLM 复核仅用于 #11 维护环的重述生成。与"LLM 提议、确定性门裁决"总边界一致。

## 四消费点（取向层的全部生效路径）

1. **生成端软引导**：soul-identity 价值锚行注入（label+方向+权重+desc）；
2. **fired 感受**：proxy appraisal 子串命中 → `<current_feeling>` 块；
3. **召回加成 + 遗忘保护**：coreRefs 命中 → coreRefBoost（tie-breaker 级，见 ADR-0001）+ salience 保护阈值；
4. **张力检测**：T1/T2 evolution reversal / 证据 valence 偏离。

## 不做清单

- **锚级 TTL/时效（GA thought 30d、mem0 expiration_date）不做**：退场由证据 retire 承担（GROW-MAINT ev<minEvidence→retire，pinned 豁免）；显式时间过期会把"证据消失"与"时间流逝"两个语义耦合，且与 veto/retire/restore 状态机重叠。
- **自动把锚升格为规则（或反向）不做**：跨层迁移必须走人工（panel 提案）。
- **desc 合同不做 LLM 强制裁决**：预筛失败不阻塞人工输入（见论证 3）。

## 落地与验收

- `DESC_CONTRACT_V2` 单一源 + 三处 prompt 接线（core-values-discover.ts DISCOVER 6b / PERSON 4b / anchor-growth.ts CHARACTER 5）；
- `passesDescContractV2` 预筛（anchor-desc.test.ts 钉死取向/定义/episode/断尾四组判定）；
- 存量审计：`MemoryCore/scripts/backfill-anchor-description.ts --contract=v2`（dry-run 审计非合同 desc → jsonl 报告；空 desc 回填维持确定性证据句路径）；LLM 重述通道归 #11 维护环（`lastDescRefreshAt`、证据 ≥2× 触发、manual origin 永不自动覆盖）；
- #7（character desc 落 attrs）实现时引用本合同。
