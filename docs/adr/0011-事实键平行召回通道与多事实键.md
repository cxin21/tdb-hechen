# ADR-0011：事实键作为平行召回通道（原文主索引不动）

- 状态：已采纳（2026-10-27，issue #137）
- 相关：ADR-0010（双时态属性契约）、issue #134（W1 事实键首版）、issue #135（检索融合）、issue #147（全开档对照）

## 背景

W1 首版（#134）把事实短语拼进**同一条** embedding 键（`buildEmbeddingKey`）。#147 全开档配对实测：
判对 −2.2pp（ns）、cov −0.6pp——**键替换形态没有净收益**，且分桶上 knowledge-update −8.3pp /
temporal −6.7pp，multi-session 才有 +6.0pp。机制解释：事实短语把「同主题」的行拉近，稀释了
「同实体不同时间」的判别信号；而 W3 结论层已经提供主题级信息，W1 的增益被覆盖、排序扰动全额保留。

同期 #135 给出融合侧证据：RRF 之后再加「合并后加性小量」（recency/validity）在 LME90 上 Δ=0
——主序是 `rrfScore` 严格降序、几乎无平局，加性小量改不了主序。要换融合层级，就得在**通道内
归一化分**上融合。

## 决定

1. **事实键从「替换主键」改为「平行召回通道」**：原文 embedding 仍写 `l1_vec`（逐位不动），
   事实短语单独 embed 写独立表 `l1_fact_vec`；召回时同一 query 向量打两路。
2. **事实来源扩到多事实**：抽取侧 `memory.extraction.facts` 门 → 每条记忆 2-5 条自足短语
   （可选三元组）→ `metadata.facts` / `metadata.factTriples`；写侧 `writeFactsOf` 统一归一化
   （去空白/长度边界/去重/条数上限），dedup 的 `metadata.subject` 保留为单短语回退源。
3. **融合分两档，缺省 RRF**：
   - `fusion.mode="rrf"`（缺省）：事实通道只**收新候选**，贡献 `weight × 1/(60+rank+1)`。
     池里已有的记录**不再加分**——否则双命中（dense 低名次 + fact 高名次）会累加两份 RRF、
     跨通道反超原文 rank1，违背「事实键只扩召回」。
   - `fusion.mode="normalized"`：各通道先做通道内归一（dense/fact = 余弦，BM25 = 通道内
     min-max），按权重合成 relevance 作主序，`rrfScore` 退回去重/平局兜底。这是 #135
     建议的「换融合层级」，显式开启才生效。
4. **权重唯一来源**：`fusion.fact > recall.factChannel.weight > 0.6`（`factChannelWeightOf`），
   `RRF_IDENTITY_WEIGHTS.fact` 不参与加法路（避免两个权重 SoT）。
5. **读侧覆盖两条召回面**：钩子自动召回（`auto-recall.searchHybrid`，支持两种融合模式）与
   `tdai_memory_search` 工具路（`executeMemorySearch`，只做通道级加权 RRF）。
6. **缺省全关**：三个开关（`extraction.facts` / `write.factKey.mode="channel"` /
   `recall.factChannel`）都缺省关。开启需要显式配置，且 pipeline 启动时若写读错配会 warn 一次。
   这不是「关掉开关规避问题」：算法形态已经改对（平行通道 + 多事实 + 通道归一化融合），
   只是 LME90 判对门禁（CI 下界 > 0）与抽取准确率门禁（≥90%）尚未跑，效果未验证前不静默
   改变生产排序。

## 后果

- **数据面**：新增 `l1_fact_vec`（vec0，同维同余弦，`IF NOT EXISTS` 老库自愈）。只有开启写侧后
  新写入的记录才有通道向量；存量库需重新抽取/回填（本 ADR 不做自动回填）。
- **成本**：每条有事实的记录多一次 embedding 外呼（LME90 实测约一半 turn 有事实）。
- **后端能力**：tcvdb 服务端 embedding 后端不实现通道方法，feature-detect 缺失 → 通道静默退出。
- **读面一致性**：工具路不做 normalized 融合（它的合并/精排是另一套），两路只在通道级 RRF 上同构。
- **观测**：钩子路新增 `timing.factMs/factHits`，命中行带 `·[fact]` 标注（诚实原则）。
- **门禁（未完成，随 issue #137 跟踪）**：LME90 配对判对 CI 下界 > 0；knowledge-update/temporal
  cov 不低于 b1-off、multi-session ≥ +3pp；抽取准确率 ≥ 90%（生产 prompt 口径）。
