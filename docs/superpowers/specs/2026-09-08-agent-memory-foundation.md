# Agent 记忆系统 · 基础设计文档（方面总览）

> 状态：讨论地基（不是实现规格）。目的：在动任何代码前，先把"记忆系统都有哪些方面"摆清楚，作为后续讨论/收敛的依据。
> 范围：面向 TDB 这套给"AI 同事团队"的记忆中枢（L0–L3）+ 前沿研究（Mem0/Zep/A-MEM/Letta + 论文）的对照。
> 主角问题：**记忆是什么？应该是什么样？怎么设计、怎么用？**

---

## 0. 一句话定位

Agent 的记忆不是"一个存储 + 一个查找"。它是一套**把经验沉淀成"能演化、会遗忘、彼此关联、最终长成身份/自我模型"的生命系统**。本文件把这件事拆分成若干"方面"，逐一列清要回答的问题。

---

## A. 概念 / 本体层（记忆到底是什么）

- **A1. 记忆的类型**（认知科学对齐）：
  - `episodic` 情节记忆（具体经历/事件，带时空）
  - `semantic` 语义记忆（事实/偏好/世界知识，去时空）
  - `procedural` 程序记忆（技能/习惯/子程序——做成可复用 Skill vs 混在权重里）
  - `working` 工作记忆（当前上下文中"正在用"的片段）
- **A2. 记忆的分层**（稳定度×价值 双轴）：L0 原始 → L1 原子 → L2 场景 → L3 画像；以及 core(常驻) vs archival(归档)。
- **A3. 记忆的本质**：不只是数据点——是**时空经验 + 关联(网络) + 会演化 + 会遗忘**。缺任何一样，都只是"缓存"不是"记忆"。

## B. 存储 / 表示层（怎么存）

- **B1. 表示形态**：孤立点记录 vs 显式关联图(A-MEM) vs 时态知识图谱(Zep) vs 向量。各有取舍。
- **B2. 时间与持续性**：只记"点状事实"会碎片化；要不要把同一主题巩固成"持续态/时长摘要"(TSM)。
- **B3. 关联 / 链接**：相关记忆之间如何连边、边如何随时间演化，支撑"邻居检索"。

## C. 生命周期层（怎么长 / 怎么变）—— 记忆的"灵魂"所在

- **C1. 写入 / 提取**：从对话/工具调用沉淀成记忆（TDB 已有 L1 extraction + priority 打分）。
- **C2. 巩固 / 聚合**：定期把 L1 → L2 场景 → L3 画像**离线重聚合**（睡眠式巩固；TSM/RMM）。
- **C3. 遗忘**：`重要性 × 时间衰减` 决定归档还是丢弃——**记忆必须会遗忘才像人**。（TDB 现在只有 priority，没有时间衰减遗忘。）
- **C4. 反思 / 更新**：Reflection(Generative Agents / RMM)：前瞻摘要 + 回顾式强化，让画像随使用改进。
- **C5. 演化**：persona / self-model 不是静态，是随巩固+反思持续生长。

## D. 利用层（怎么用）—— 目前 TDB 最聚焦、但只是"最后一段"

- **D1. 召回**：语义 / 图(邻居) / 时态 / 组合检索；TDB 的 L1 现有 hybrid(RRF) 但有"门槛未启用"缺陷。
- **D2. 注入**：**什么时候注**（每轮 vs 按需 anchored）、**注什么**（core 稳定 vs episodic 动态）、**位置**（稳定前缀 vs system 末尾）、**预算**、**cache 纪律**（session_init 锚定区）。
- **D3. 门控**：宁缺毋滥 + 绝对相关度门槛 + 优先级加权（在 wiki 召回已验证的教训可复用到记忆）。
- **D4. 工具**：按需检索能力（tdai_memory_search / scene read）与调用上限。
- **D5. 上下文编排**：working memory 在窗口里怎么放、怎么淘汰（compaction 不是记忆）。

## E. 能力 / 边界层

- **E1. 程序记忆落地**：procedural 做成可执行 Skill（TDB 已有）vs 论文的 Mem^p。
- **E2. 信任边界 / 安全**：被注入记忆可能是投毒载体；来源可信 + 消毒 + 长度上限。
- **E3. 可观测性**：指标（Recall/Precision、重要性演化）、审计溯源、golden 回归。

## F. 身份 / 自我模型层（"灵魂"）

- **F1. 可演化的 persona**：L3 画像随巩固/反思更新，而不是建完即死。
- **F2. agent 可维护的 core**（Letta 式）：一小块"身份/偏好/严格规则"让 agent 能主动读/维护。
- **F3. 一致性 / 连贯性**：跨会话言行一致（不出现"I don't remember you"），才是"有灵魂"的体感。
