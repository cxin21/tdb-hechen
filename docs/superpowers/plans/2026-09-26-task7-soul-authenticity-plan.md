## 一、问题定义

「灵魂真伪」不是判断灵魂像不像人，而是判定**灵魂注入块的忠实性与健康度**——注入块是否忠实反映结构化记忆证据、是否被生成链污染（幻觉锚/无中生有的价值观）、是否构成自强化循环（回音室）、是否跨租户串味。灵魂四段（身份/价值锚/品格/感受）中每一条在场内容都应有可回查的结构化来源；不可溯源的内容即「伪」。

## 二、三维量化判据

### 维度 1：溯源率（Groundedness）——目标 ≥95%

- **定义**：`/v3/recall` 返回的灵魂注入块（锚行/锚 description/品格行/身份行）逐行反查结构化来源（core_values / core_memory / identity 行，含 origin/created_by/slot version 链），可匹配行数 / 总行数。
- **探针配方**：复用 recall-anchor.mjs 的 OFF 相位（TDAI_ANCHOR_ON_OVERRIDES 全 OFF，determinism PASS 形态）——灵魂段不依赖召回排序开关，OFF 相位测量隔离变量。
- **已知豁免集**：感受段首要段（moodLine，运行态聚合非锚行）、锚行 w 值（推导值非存储值）、五徽章（formatMemoryLine 渲染层）。豁免集之外的不可溯源行=伪内容。
- **测量口径**：N≥3 次真实租户快照（主租户+测试租户 ev17+seed 桶），每快照逐行判定，汇总比率。**判定表必须给出行级明细（命中行/豁免行/伪行各列文件:行）**，不接受纯比率。

### 维度 2：换用户/换 agent 双测试分化率

- **定义**：灵魂内容必须随租户分化——同 agent 不同用户桶：每桶灵魂段 ≥1 条唯一事实（他桶零出现）；同用户不同 agent 桶：self_identity/品格段差异 ≥1 条（默认人格退化断言）。
- **数据基础**：任务 2 golden 桶重建产物（25 L1+3 reflection）+B 工作流双测试（c07f75c，真实数据通过在案）+租户三元组样本 ≥10 组（复用 runs 归档租户清单）。
- **判定口径**：分化失败（两桶灵魂段逐字相同且非默认人格）=真伪不通过；默认人格回退（空桶）不算失败但计入覆盖率注记。

### 维度 3：反自我强化审计（零触发）

- **定义**：灵魂生成→注入→再提取的回路中，不得出现正反馈自强化。三条红线断言：
  1. **R-A**：mood 聚合永不入召回排序——`computeMoodValence` 与 `emotionSalienceOf` 各只一份（vitest 静态断言，防复制漂移）；
  2. **F14-bis**：自我注入内容不回灌 L1 记忆池（注入块的 soul 段不进入提取语料——语料窗取证断言）；
  3. **红线类唯一写通道**：identity/self_identity/core_value/strict_rule 生成内容永不自动落库，core_pending+Panel 裁决是唯一通道（V12-CV 后 core_value 采纳链已闭合：label 门+422 不暗箱裁决）。
- **测量**：①vitest 静态断言套件（一次性成文）②journal 14 天扫描「自驱直接落库/绕过 pending」零事件。
