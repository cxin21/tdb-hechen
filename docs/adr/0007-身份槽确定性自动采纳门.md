# ADR-0007 身份槽确定性自动采纳门（stage 2）

- 状态：已接受（2026-10-25 用户拍板「启动 stage 2」+ 四项推荐参数确认：N₂/T₂=4/72h · 0.60/0.75 · 快照+版本守卫回滚 · 面板跟进票）
- 关联：#92（实施票）、#91（计票基建，已关）、#81（洪泛止血，已关）、ADR-0005（身份叙事层）

## 背景

#91 落地「复现即投票 + 默认终局」后，core_pending self_identity 行带可信复现账本（count / first_seen / last_seen / episodes）。现行约束：人格槽写入必须人审（#81 保守底线）——ready 行仍逐条等人裁决，而人工裁决带宽实测趋近 0（#91 根因①）。约束变更（人格写入终审权部分让渡给确定性门）必须单独拍板，故立 #92 分票。

## 决定

1. **三重门**（全部满足才自动采纳，缺一退回人审）：
   - count≥N₂=4 ∧ 跨度≥T₂=72h（比 stage-1 ready 的 votes=3/72h 严一票；跨 3 天持续复现 = 慢变量真自我事实）；
   - 无同主题 rejected 矛盾：proposalSimilarity(content, 任一 rejected 行) ≥ 0.60（宁拦勿收——误拦=退回人审安全方向，漏拦=误收污染不可自动修复）；
   - 非槽内重复：proposalSimilarity(content, 任一现行槽行) ≥ 0.75 → 跳过（沿用 proposal-dedup 单一源标准）。
2. **采纳链单一源**：逐位镜像 #82 人审 merge-on-adopt（readCore → escapeXmlTags 按行消毒 → mergeIdentityFacts → 幂等跳过 → upsertCore source="auto-adopt-gate"）；不新发明写链、不绕 vet、槽行守恒 IDENTITY_MAX_FACTS=8。
3. **可逆（快照+版本守卫）**：采纳时快照 prev_slot_content/version/存在性 + post_version 入 attrs_json.auto_adopt；回滚 = 既有 decide 路由 rejected 打在 auto_adopted 行 → 版本守卫（现行槽 version ≠ post → 409 提示手工处理）下恢复快照（或删除采纳时创建的槽行）；零删除，recurrence/attrs 证据全留。
4. **config-first 缺省关**：lifecycle.reflection.selfIdentityGate.autoAdopt.enabled 缺省 false = 逐位现状（晋升只到 ready-for-human）；生产启用由用户部署时显式写 yaml——人格写入终审权变更的最后一道闸在部署面。
5. **人转审计员**：auto_adopted 为新终局态（状态机扩展已按 #91 R1 教训审计全部 state 字面量过滤点）；面板审计徽标+回滚入口走跟进票（回滚 API 复用 decide 路由，面板零 API 变更）。

## 理由

- 代价不对称：误收（人格污染）不可自动修复、误拦只多一次人审 ⇒ 精度优先：更严的 N₂、矛盾线低于重复线（0.60 < 0.75）。
- 判定放置：复现证据只有 DB 侧看得见（#91 已证「生成端放判定」是错层）；「LLM 提议、确定性门裁决、人转审计」是身份槽的完全体。
- 快照回滚：仅翻状态的回滚会把被否事实留在人格槽，「可逆」名不副实——对 #92 草案的一处收紧（2026-10-25 拍板③）。

## 后果

- 生产观察窗验收：auto_adopted 精确率（用户零回滚占比）呈报后定线；N₂/T₂/阈值按 #80 法真实数据复核可调（config 键承载，不散落魔法数）。
- 诚实边界：第一误收仍须回滚+审计；陈旧身份无自动降级通道的既有边界不在本决定解决。
