## 3. 三类注入物 × 三种时机（规约）

1. **身份/价值锚 = 性格（disposition）**：会话头 + 指纹缓存（soulVersion）；远端前缀。
2. **红线 = 不变量（invariant）**：会话头独立段（#24-C1）+ 动作点近端重注入（#37 `tools.before_call`，待接线票）；常驻远端对红线是主动错误（长上下文稀释）。
3. **感受/状态 = state**：每轮按当下计算（#28/#34）；历史聚合降级为基线（mood 行）。

子代理（D4）：默认无灵魂；长生命周期子代理（>N 轮）是否裁剪注入身份=后续评估项，不预设。

## 4. 真实性边界（硬边界，反目标）

- **不伪造当下体验**：注入文本不得声称第一人称感受；state 只渲染聚合实况（#34 文案不含「我感到」）。
- **不自欺**：LLM 不得直改承诺状态（D8）、不得绕过提案门改身份（#27 白名单+verbatim 门）。
- **红线不软化**：渲染分层后红线原文逐字保留、无预算截断、无改写（#24-C1 不变量）；执行位（#37）不得以任何「上下文紧张」理由降级。
- 宁缺毋滥：一切渲染段空数据整段省略（价值锚行/红线段/能力段同规）。

## 5. 批次纪律（渲染字节跳变）

渲染布局/命名的任何变更 = 一次显式声明的字节跳变（生产 soulPrefixCache 为进程内存态，随重启自然刷新）；soulVersion 只由数据（slots+values+moodTier.tier）驱动，布局变更不翻 sv（批次纪律语义勘误：**渲染字节一次性变化**，非 sv 跳变）。

#67（R3 身份叙事层，2026-10-19）按本条纪律声明首批叙事模板指纹：`NARRATIVE_TEMPLATE_VERSION = "nv-2026-10-19-1"`（单一源 `MemoryCore/src/core/hooks/identity-narrative.ts`），作为 nv 段参与 soulPrefixCache cacheKey（仅 identityNarrative 开启时出现，缺省键逐字节不变）；模板文案变更须换新 nv 值一次性声明，soulVersion(sv) 维持数据驱动不翻。
